# Cognium

A local-first AI platform

## Features

- Local LLM inference
- Chat history
- Streaming responses
- PostgreSQL support
- Docker integration
- Configurable inference parameters

## Requirements
- Docker
- Docker-compose
- Python 3.10+

## Installation
1. Clone this repository.

2. Install project dependencies:

```bash
    python install.py
```

## Running
Start the application:

```bash
    python start.py
```

Then open your browser at:

http://localhost:8080
